# Passenger cabin ambience

FreeFlight Cabin Control can loop an optional local passenger-ambience recording through the Windows playback endpoint.

Place a user-owned or properly licensed recording here with this exact filename:

`Passenger_Cabin_Ambience_Loop.mp3`

The Audio page detects the file on launch. Its Passenger Ambience switch, volume slider, play/stop button, master volume, and persistent page playback then control the loop. The public package does not include a crowd recording unless redistribution permission has been documented.
